`docs/README.md` is the index with one line per file and the ADR pointer for the moved path. C4 (Mermaid): level 1 context and level 2 containers in `explanation/architecture.md`; the existing `system-light/dark.mmd` and `.svg` pair moves to `explanation/diagrams/` and is regenerated by a script (manifest kept); a check fails if the `.svg` is older than the `.mmd`.

Threat model (`explanation/threat-model.md`, M3): STRIDE-lite over the six surfaces (OAuth callback, session cookie, invitation link, server actions, private ops read, metrics endpoint), assets (owner account, IAM data, API bearer), trust boundaries (browser, backoffice, API, PostgreSQL, OAuth provider), abuse cases mapped to the tests that cover them (authz matrix, CSRF, state mismatch, replay, rate limit, invitation reuse, last-owner removal, secret leakage into RSC payload), residual risks (real OAuth config, TLS cookies, proxy header trust until `vps-ops`). Each row cites a test name; a test fails if a cited test is renamed away.

Docs CI (docs profile): markdownlint-cli2, lychee (also weekly cron on all docs), Vale on English prose, `check-docs.ts` (local links today: 141 checked, 0 missing; extended with README required headings and the ecosystem version stamp), skills validator. Docs-only PRs run only these plus secret scan and the gate.
