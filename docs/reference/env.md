# Environment variables

Generated by `scripts/generate-env.ts` from the descriptions in `src/server/environment-variables.ts`.
A dash indicates that no value is supplied by default.
Production requires at least one complete OAuth provider pair.

## Backoffice runtime

| Variable | Requirement | Default | Purpose |
| --- | --- | --- | --- |
| `NODE_ENV` | Optional | — | When `production`, selects production mode by default and restricts test mode to a loopback origin. |
| `BACKOFFICE_ENVIRONMENT` | Optional | `production` if `NODE_ENV=production`, otherwise `development` | Selects `development`, `test` or `production`. A production build refuses development mode. |
| `BACKOFFICE_ORIGIN` | Required in production | `http://localhost:3201` outside production | Exact public origin for the app and OAuth callbacks. Production requires HTTPS. |
| `BETTER_AUTH_SECRET` | Required outside test mode | Built-in test secret in test mode | Better Auth signing secret. Supply at least 32 characters outside test mode. |
| `DATABASE_URL` | Required in production and with test-only auth settings | `postgres://localhost:5432/backoffice` outside production | Backoffice PostgreSQL connection string. Test-only auth settings require an explicit disposable loopback database. |
| `OWNER_EMAIL` | Required in production | — | Provider-verified email admitted as owner without an invitation. |
| `GOOGLE_CLIENT_ID` | Required when configuring Google | — | Google OAuth client ID. Set with `GOOGLE_CLIENT_SECRET`. |
| `GOOGLE_CLIENT_SECRET` | Required when configuring Google | — | Google OAuth client secret. Set with `GOOGLE_CLIENT_ID`. |
| `GITHUB_CLIENT_ID` | Required when configuring GitHub | — | GitHub OAuth client ID. Set with `GITHUB_CLIENT_SECRET`. |
| `GITHUB_CLIENT_SECRET` | Required when configuring GitHub | — | GitHub OAuth client secret. Set with `GITHUB_CLIENT_ID`. |
| `AUTH_TEST_ISSUER` | Optional | — | Loopback fake OIDC issuer for automated tests. Refused in production. |
| `AUTH_DISABLE_RATE_LIMIT` | Optional | Limiter enabled | Set to `1` to disable per-IP sign-in rate limiting for automated tests. Refused in production. |
| `OPS_API_URL` | Required when setting `OPS_READ_TOKEN` | — | Private operations API base URL. Use HTTPS or an allowed internal HTTP host. |
| `OPS_READ_TOKEN` | Required when setting `OPS_API_URL` | — | Private operations API bearer token of at least 32 characters. |
| `OPS_API_INSECURE_INTERNAL_HOSTS` | Optional | — | Comma-separated additional internal hosts allowed for HTTP operations API requests. |
| `OPS_TELEMETRY_ENABLED` | Optional | `false` | Enables reads of private operational telemetry when set to `true`. |
| `PRODUCT_ANALYTICS_READ_ENABLED` | Optional | `false` | Enables reads of private product analytics aggregates when set to `true`. |
| `TRUSTED_PROXY_IPS` | Optional | No trusted proxies | Comma-separated IP addresses or narrow CIDRs trusted to supply `X-Forwarded-For`. |

## Observability

| Variable | Requirement | Default | Purpose |
| --- | --- | --- | --- |
| `OBSERVABILITY_METRICS_ENABLED` | Optional | `false` | Enables the private metrics endpoint when set to `true`. |
| `OBSERVABILITY_READ_TOKEN` | Required when metrics are enabled | — | Private metrics bearer token of 32–256 characters without whitespace. Must differ from `OPS_READ_TOKEN`. |
| `OBSERVABILITY_TRACES_ENABLED` | Optional | `false` | Enables the isolated trace exporter when set to `true`. Ambient `OTEL_*` settings are refused while enabled. |
| `OBSERVABILITY_OTLP_TRACES_ENDPOINT` | Required when traces are enabled | — | Private OTLP HTTP JSON endpoint at `/v1/traces`. Use HTTPS or an allowed internal HTTP host. |
